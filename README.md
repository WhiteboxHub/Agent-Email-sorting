# Email Classifier

This project fetches emails from a Gmail account, classifies them into categories (UI, ML, QE), and moves them to the corresponding labels.

## Setup

1. Clone the repository.
2. Create a virtual environment and install dependencies:
   ```bash
   python -m venv venv
   source venv/bin/activate  # On Windows use `venv\Scripts\activate`
   pip install -r requirements.txt
